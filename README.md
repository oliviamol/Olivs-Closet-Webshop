#  Oliv's Closet

**Oliv's Closet** este un proiect de tip magazin online realizat în perioada liceului. Acesta reprezintă primul meu pas în dezvoltarea web, fiind creat pentru a învăța cum să construiesc o interfață atractivă și funcțională de la zero.

  ## Despre Proiect
Acest site a fost un exercițiu de învățare bazat pe tutoriale practice, unde am explorat modul în care elementele vizuale interacționează cu utilizatorul. Proiectul simulează experiența unui magazin online de haine, punând accent pe design.

 ## Tehnologii folosite
- **HTML5**: Pentru structurarea conținutului paginilor (produse, descrieri, secțiuni de navigare).
- **CSS3**: Pentru stilizarea magazinului, layout-uri responsive și aspectul vizual (culori, fonturi, așezare în pagină).
Am utilizat JavaScript pentru a adăuga un nivel de interactivitate necesar unui magazin modern:
- **Interactive Quiz**: Creat pentru a ajuta utilizatorii să câștige diferite vouchere.
- **Add to Cart System**: Implementarea unei funcții care permite utilizatorilor să adauge produse în coșul de cumpărături în mod dinamic, îmbunătățind experiența de navigare (UX).

## Evoluție și Învățare
Realizarea acestui site m-a ajutat să înțeleg fundamentele web-ului:
1. Cum să organizez codul într-o structură logică.
2. Cum să folosesc JavaScript pentru a face paginile "să prindă viață".
3. Importanța detaliilor vizuale în atragerea utilizatorilor.
